# math-knowledge-mindmap
将数学教材、讲义和笔记整理为中文思维导图，支持精简、标准、深入三种模式。用彩色箭头标注推导难度，用虚线区分知识点的关联强度，并用嵌套分组展示包含关系，方便复习定理条件和解题方法。
# 数学知识点思维导图 Skill

成员：魏绮遥10241510455 侯嘉仪10241510481 文馨瑶10241510463

这个 Skill 把数学教材、课堂笔记或指定主题整理成中文思维导图，
在图中呈现定义、定理条件、核心公式和解题方法。

## 主要功能

- 提供精简、标准、深入三种模式，默认使用标准模式。
- 用彩色实线箭头标记推导难度，用彩色虚线标记知识点关联程度。
- 根据内容选择树形、网络或嵌套分组布局，区分推导关系与包含关系。

## 使用示例

提供一段关于度量空间紧性的讲义，然后输入：
“请用标准模式整理紧性、列紧、完备性和全有界性的关系，
标明关键推导的条件，并区分推导难度和关联程度。”
